# Town · 游戏介绍站

[打开网页](https://rahmayamanaka-star.github.io/Town/)

独立于 `../frontend/` 游戏项目的 React / Vite 网站。首页、文案和流程遵循内容审核 V2：代码加载 → Town → 简介 → 展示 → 玩法 → 尾页。体验入口暂不实现。

## 本地运行

```powershell
cd Town
npm ci
npm run dev
```

打开 http://127.0.0.1:5174/ 。`npm run build` 生成 `dist/`；`npm run preview` 预览生产构建。原游戏继续使用 5173 端口。

## 本轮更新

### GitHub Pages 发布准备

项目根目录包含 `.github/workflows/pages.yml`，推送到 `main` 后自动检查、构建并发布。仓库须先在 Settings → Pages → Source 选择 GitHub Actions。

构建从 Pages 元数据读取网站路径和域名：项目站点可位于 `/仓库名/`，个人主页也可直接位于 `/`。识别码、字体与其他静态资源随该路径加载；不需要额外令牌。`PAGES_BASE_PATH` 与 `SITE_URL` 仅在构建时使用，默认构建仍使用当前站点配置。

- 松鼠采用圆润头身、独立脸颊与耳朵、抱果爪子、橡果和渐变粗细的大卷尾，保留黑色轮廓与漫画网点。
- 花海按完整花片的边界避让实际放大后的树底座，同时给松鼠留出位置；底座边缘不再穿过花片。
- 钓鱼剧情改为纯滚动推进：垂钓 → 冰洞动静 → 惊跳/感叹号 → 鱼竿落地。停止滚动会保持姿势，反向滚动可以回看，鱼竿最终保持落地。
- 绕屋进门增加 150vh 滚动距离，路线约为之前的 4.25 倍；冬季剧情增加 180vh，完整动作有 243vh 的滚动区间。章节按钮同步使用分段位置映射。
- 切换云采用不重复的圆润云团轮廓，分成大云层和小云絮；各自的大小、比例、角度与网点疏密都有差别。

- 顶部章节刻度条随滚动推进，可点击回看；生活标题使用独立前景层，不再被定位板覆盖。旁边的小棋子随滚动弹跳进屋，门先开后关。
- 原有 330vh 展示之后增加 900vh 的连续天气段：生活 → 阴雨傍晚 → 秋天 → 冬天。云片按定位板投影的平行平面从左侧扫入，遮住标题时换字；“多”使用季节强调色。
- 雨天包含全屏细雨、地表与水面涟漪、低处薄雾和暖窗；秋天改变地形与树冠颜色并加入落叶、南瓜；冬天增加屋顶、树冠与地表积雪、飘雪、带真实孔洞的冰面和冰裂纹。
- 天气材质从展示小镇的源材质单独克隆，避免影响现实/想象转场及玩法模型；降水与涟漪使用实例或批量绘制，云层跟随滚动，环境动画仍只在可见视图更新。

## 保留的镜头与交互

- Town 先加速放大至约 3.05 倍，短暂停留后才融合扩展，形成更明显的撞入感。
- 摄像头随滚动轻转，明亮扫线和拖尾扫过实体标记时触发一次弹性跳跃，并亮起识别光环。
- 房屋采用单片曲面屋顶、圆角墙体、拱门和圆窗，取消瓦缝与繁杂门廊，减少重叠描边。
- 想象页末段先出现黑白虚线，动漫剪刀沿地块和树冠外缘剪切；虚线始终提前至少一段，剪完后纸片抬起、镜头推近，再连续接入单块陆地。原定位板和其余物件保持原尺寸，由纸面遮罩覆盖。
- “现实，”与“搭进想象”使用真正的挤出文字，字面垂直立起；后者沿画面右上方板边的平行方向排布，包含立体侧面和黑色轮廓。
- 剪完后的完整虚线跨过镜头放大和页面交界持续保留，进入陆地展示段后向外扩出视窗。标题与花海延后展开，转场覆盖区间也支持反向滚动和快速跳转。
- 陆地、海洋、生活的标题分别设计为草芽与土层、水纹与气泡、暖色建筑与窗格；陆地花海改为密集、贴地的平面花片，使用三组实例绘制。
- 门板整体移到墙体倒角前方，避免相邻表面争抢深度造成滚动闪烁；几何检查会验证完整门板与墙面之间的间距。
- 保留探头松鼠、海洋循环跃鱼、起跳与落水的水花和涟漪。均为介绍站中的交互示意。
- 依然使用单一 WebGL 画布、共享几何体和材质、可见视图绘制以及约 30 fps 的环境动画；减少动态效果时保留静态替代。

## 基础行为

- 开场逐行敲字，无进度条。字体和三维场景准备好后才完成最后一行；光标持续闪烁，随后由实体黑色遮罩承接放大，避免整屏闪烁。
- 代码输入略放慢，行间停顿增加。Town 使用 Manrope 800 的真实字形路径，依次绘制白色轮廓，再从下向上填白；绘制期间暂停滚动，完成后解锁。
- 滚动先让现实场景从 Town 字形内部透出，字形轮廓逐渐加粗并合并为一块连续开口，向外铺满视窗；内容保持原位，不再通过放大淡出切页。返回首页保留已完成的字形，不重播加载。
- 简介为同一位置叠加的两个全屏场景：实体编码板和漫画风虚拟小镇。立体标题沿板面边缘出现，竖向扫线随滚动从左到右把现实转换为想象。完成剪纸后通过树地块推近镜头进入下一展示段；End 键等大幅跳转不会被拽回。
- 现实场景使用金属底座、橡胶脚、螺丝刻度、木纹方块、纸质贴纸和接触阴影，增加支架摄像头与轻量扫描光带。想象标题为白心黑色粗边框；房屋增加瓦缝、门廊、窗框和踏步。想象场景采用黑色粗描边、卡通色阶和网点阴影，房子与树的比例做了适度夸张。两层相机、板面大小和网格位置一致。示意没有冒充摄像头实拍，也不请求设备权限。
- 展示阶段通过滚动切换陆地、海洋、生活；玩法阶段依次铺地形、放物品、移动整组方块到不同合法格。
- 现实/想象的标题与正文随扫线切换，想象层使用自托管的站酷快乐体子集。海面使用像素水光，树有三片轻落叶，烟囱从扫线 75% 后渐起四个错时、分离的卷曲网点烟团。
- React Bits ScrollReveal 用于玩法标题。GSAP ScrollTrigger 组织滚动叙事，Lenis 使用同一个 GSAP ticker。
- 一个透明 WebGL 画布以 scissor 渲染可见视图，DPR 上限 1.5；共享几何体与材质，静态部分按需重绘；水光、落叶和烟雾只在对应视图可见时以约 30 fps 更新，滚动输入优先重绘。离屏视图不绘制，后台标签停止重绘，静态场景复用阴影贴图。
- 本轮仅制作和验收电脑横屏，不提供手机专用布局。`prefers-reduced-motion` 下跳过描边、缩放、平滑滚动与长滚动段，显示完整静态布局。WebGL 不可用时显示 SVG 示意。

## 人工审核建议

首次打开看加载转场；完整滚动一遍观察三个展示阶段和三个玩法阶段；点击回到开头；在电脑横屏下停住滚动，查看水面、落叶和烟雾。在系统中启用“减少动态效果”后刷新检查静态版本。实际摄像头识别与游戏操作仍在原游戏中测试。
